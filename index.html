QuickGrade Start grading

Grading a stack of tests shouldn't take all evening.

I built QuickGradeCalc so teachers can set the question count once, tap +1 wrong for each miss, and read off the percentage and letter grade. It's free and needs no sign-up.

Try the free grade calculator

What it does

Fast grading

Tap +1 wrong or press W for each miss and grade a whole stack in seconds.

Your grade scale

Set your own minimum percentages for A, B, C, and D.

Printable quick chart

See the grade for every possible score and print it for your desk.

How it's built

Next.js and Tailwind CSS, hosted on Vercel. It runs in any browser on phones, tablets, and desktops. Read the grade calculator guide or use the percentage to letter grade calculator.
